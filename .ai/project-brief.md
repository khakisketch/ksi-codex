# Project Brief

## Goal

Publish the owner's active portable Codex behavior as a private, versioned
installation bundle for another personal computer.

## Scope

- Current global `AGENTS.md`
- Current read-only `explorer` agent
- Current command rules
- Portable, secret-free config profile
- Backup-first installer, checker, documentation, and copy/paste install prompt
- Private GitHub repository and versioned release

## Non-goals

- Copying authentication, sessions, memories, browser profiles, or caches
- Reproducing absolute project paths or trusted project entries
- Automatically completing plugin OAuth or account login
- Installing historical KSI skills or specialized agents by default

## Acceptance

- Source validation has no failures.
- Isolated install matches the portable source exactly.
- Existing local Codex files are unchanged during verification.
- Private remote and release are reachable through the authorized GitHub account.
